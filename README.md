# Zweiradmeisterei

One-page site for the Meister bicycle workshop in Köln-Sülz.

## Production

https://zweiradmeisterei.vercel.app

Source: https://github.com/Teomen77/zweiradmeisterei

## Local

```bash
npm install
npm run dev
```

Facts live in `src/lib/site.ts`. Workshop photographs in `public/` are generated stand-ins, not photos of the shop. Weekend hours are unpublished. Impressum and Datenschutz are stubs.
